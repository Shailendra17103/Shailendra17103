An intelligent classroom attendance platform that automates attendance using **dual biometric authentication** through facial recognition and voice verification.

### ✨ Highlights

- 🔹 Dual biometric authentication using **Dlib** (Face Recognition) and **Resemblyzer** (Voice Verification)
- 🔹 Multi-face classroom attendance from a single image
- 🔹 QR-code based student enrollment
- 🔹 Secure cloud storage using **Supabase**
- 🔹 Interactive dashboard built with **Streamlit**
- 🔹 Automated attendance reports and analytics

**Tech Stack**

`Python` • `OpenCV` • `Dlib` • `Resemblyzer` • `Streamlit` • `Supabase`
